Issue with AI

Does a new AI model make its own coding agent’s bug tracker better or worse?

Every few weeks OpenAI or Anthropic ships a new model. Both labs also run public GitHub trackers for their coding agents. We lined up 52 model and product releases against every issue ever filed in openai/codex and anthropics/claude-code. For each release, we measured how the backlog of open issues changed over the next 14 days. The data, code and method are all on GitHub.

On average, launches don’t move the backlog. The extremes are another story.

Release dates line up with backlog moves; that’s correlation, not causation. The snapshot doesn’t record who closed an issue, so bot clean-ups and human triage look the same.

How the numbers are made

Backlog

Every issue in each repository comes from the GitHub GraphQL API (pull requests excluded). “Open issues” is the end-of-day count, by UTC calendar date.

Release moments

Releases come from AI Release Tracker and official announcements. Releases within 7 days of each other are grouped and measured from the first one.

Verdicts

The change in open issues from the release day to 14 days later, as a share of the backlog on release day: at least +10% is a boom, −5% or lower is a bust.

Closing before a launch

Issues closed per day in the 7 days before a release, divided by the rate 8–35 days before. 1.0× means business as usual.
